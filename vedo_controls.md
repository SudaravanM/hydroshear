# Vedo Demo Controls

#### Translation Controls (Object)
<div align="center">

| Key | Action |
|-----|--------|
| w | Move object +Y (step size) |
| s | Move object -Y (step size) |
| a | Move object -X (step size) |
| d | Move object +X (step size) |
| q | Move object +Z (step size) |
| e | Move object -Z (step size) |

</div>

#### Rotation Controls (Object)
<div align="center">

| Key | Action |
|-----|--------|
| i | Rotate +X (5°) |
| k | Rotate -X (5°) |
| j | Rotate +Y (5°) |
| l | Rotate -Y (5°) |
| u | Rotate +Z (5°) |
| o | Rotate -Z (5°) |

</div>

#### Camera Controls
<div align="center">

| Key | Action |
|-----|--------|
| ↑ (Up) | Move camera up (Elevation +) |
| ↓ (Down) | Move camera down (Elevation -) |
| ← (Left) | Move camera left (Azimuth -) |
| → (Right) | Move camera right (Azimuth +) |
| c | Toggle Top-Down View / Normal View |
| t | Toggle Auto-Rotation (camera orbits object) |

</div>

#### Visualization Toggles
<div align="center">

| Key | Action |
|-----|--------|
| 1 | Toggle Force Arrows |
| 2 | Toggle Shear Arrows |
| 3 | Toggle Tactile Point Cloud (Yellow) |
| 4 | Toggle Indenter Point Cloud (Cyan) |
| 5 | Toggle Indenter Frame |
| 6 | Toggle Contact Circle (Red) |

</div>

#### Simulation / System
<div align="center">

| Key | Action |
|-----|--------|
| z | Reset Object to Initial Pose |
| m | Take Screenshot (`hydroshear_demo_vedo_screenshot.png`) |
| r | Start/Stop Recording Poses |
| p | Replay Recorded Poses (`recorded_poses.npy`) |
| v | Save Video of Recorded Poses (`hydroshear_demo.mp4`) |
| f | Save Frames of Recorded Poses (`recorded_frames/`) |

</div>
